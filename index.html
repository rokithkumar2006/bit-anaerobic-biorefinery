Research planning · Low budget

Data collection plan

A staged workflow for starting from zero with partial laboratory access. Record measured campus data separately from literature values and simulated outputs.

Stage 1

Campus waste survey

For 7 consecutive days, record date, source, waste category, wet weight in kg, collection period and unusual conditions. Keep hostel, canteen and garden streams separate.

Scale and logbook
Stage 2

Available lab tests

Ask the lab supervisor which tests and replicates are feasible. Prioritize moisture / total solids and volatile solids for representative samples. Record method, units and sample ID.

Use existing facilities
Stage 3

Literature supplement

Find published anaerobic digestion experiments using similar food or vegetable waste. Extract feedstock, operating conditions, gas yield, methane fraction, units and the exact paper reference.

A campus waste survey alone cannot provide methane yield. That output requires digestion experiments or suitable published experimental records.

Sample handling and quality

  • Get campus and laboratory approval before collecting samples.
  • Label each sample with a unique ID, date, source and collection time.
  • Follow the lab's approved sample storage and test procedures.
  • Run replicates where feasible and keep raw observations, not just averages.
  • Never invent missing values; use “not measured” and cite literature sources.
  • Keep simulation outputs in a separate table from measured or published results.

Suggested spreadsheet columns

Record ID · date · waste source · waste category · wet weight (kg) · moisture (%) · TS (%) · VS (state basis) · C/N · pH · temperature (°C) · HRT (d) · OLR (kg VS/m³/d) · inoculum ratio (define basis) · biogas volume (state units and duration) · methane (%) · methane yield (state basis) · data source type · paper / method reference · notes

For ML, use comparable experimental rows with measured outputs. Keep papers and experiments identifiable, and split training/test data by experiment or study where appropriate to reduce leakage. Do not report predictive accuracy until independent validation is done.

Research resources

Open-source simulation tools

Existing research software can help you build a more defensible anaerobic digestion model. These are external projects, not built-in engines in this website. Check each repository's license, installation requirements and documentation before using it.

QSDsan

Best starting point for integrated process and resource-recovery studies.

Python framework for process modelling, dynamic simulation, techno-economic analysis and life-cycle assessment. It includes anaerobic digestion models and unit operations.

Source code and license · Documentation

Recommended for system-level study

PyADM1

A direct route to learning the ADM1 model.

Python implementation of Anaerobic Digestion Model No. 1. It uses SciPy to simulate dynamic reactor behaviour and can be adapted with characterized feed and initial conditions.

Source code and license

Useful for model learning

ADM1F

For faster mechanistic simulation.

An open-source implementation of ADM1 designed for fast, numerically stable simulation. Review its PETSc setup and tutorial before deciding whether it fits your computing environment.

Source code · Tutorial

Advanced numerical model

PyADM1ODE

For plant-level biogas modelling and optimization.

Python framework for modelling and simulating agricultural biogas plants with ADM1, including configurable plant components and example notebooks. Check its current documentation and dependencies.

Source code and license

Plant configuration focus

How to use these in the BIT project

  1. Start with QSDsan or PyADM1 and run an included example before changing parameters.
  2. Collect campus waste quantity and characterization data, then document all literature-derived parameters.
  3. Compare simulated outputs against published or measured biogas and methane yields. Do not report model accuracy until validation is complete.
  4. Keep this website as the project dashboard, and connect a chosen model through a Python backend only after the model runs reliably.

Open-source does not mean zero setup. These tools are primarily code-based and may require Python, scientific packages and model calibration. Their outputs are not automatically validated for BIT campus waste.

Terms & conditions

Conditions for using this academic prototype.

1. Purpose

This website is an educational and research prototype for exploring anaerobic digestion of campus organic waste. It is not a certified engineering design, operational plant controller or commercial guarantee.

2. Data and estimates

Unless a value is explicitly identified as measured or supported by a cited source, treat it as an illustrative simulation input or output. Results depend on assumptions and should not be presented as experimental findings.

3. No operational reliance

Do not use the calculations alone to design, construct, operate or make safety decisions for a physical digester. Obtain qualified engineering review and validate process parameters experimentally before implementation.

4. Research use and attribution

Users are responsible for checking source material, citing published data, and distinguishing their own measurements from literature values. Do not submit simulated results as measured observations.

5. Availability and accuracy

The prototype is provided for demonstration and may contain errors or incomplete features. No warranty is made that outputs are complete, accurate or suitable for a particular purpose.

6. Changes

These terms may be updated as the project develops. The page should be reviewed before public deployment and adapted to the institution's requirements.
